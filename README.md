# BookNest

Персональный трекер книг: что читаю, что прочитано и что в планах - с поиском и фильтрацией по автору, названию и жанру.

## Стек

- PHP 8.5
- Symfony 8.1.4
- Doctrine ORM
- PostgreSQL
- Twig

## Функции

- Добавление, редактирование и удаление книг (с валидацией полей формы)
- Присвоение книгам жанров (связь ManyToMany)
- Статус чтения: читаю / прочитано / в планах
- Рейтинг книги (1–5)
- Поиск по названию и автору
- Фильтрация по жанру и статусу
- Пагинация списка книг
- Авторизация пользователей — у каждого своя библиотека
